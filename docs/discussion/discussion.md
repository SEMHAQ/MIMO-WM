# 讨论

本节综合实验结果，讨论 MIMO-WM 的核心定位、精度与轻量化的协同优势，以及它在世界模型谱系中的位置。

## 核心论点：精度与轻量化兼得

MIMO-WM 的价值不在于"在单一维度上碾压所有方法"，而在于 **同时实现最优精度与最少参数量**——在精度—参数—速度的三维权衡中占据帕累托前沿。

```
精度（R²）排名：    MIMO-WM ≈ Transformer > Mamba > TCN > GRU > LSTM
参数量（M）排名：   MIMO-WM (0.138) < TCN (0.189) < GRU (0.190) < Mamba (0.224) < LSTM (0.227) < Transformer (0.302)
推理速度视序列长度与模式而定
```

!!! success "综合最优"
    MIMO-WM 在 Humanoid 上取得最优精度（MSE = $19.87 \times 10^{-2}$，$R^2 = 0.751$），同时参数量最少（0.138 M）。这种"精度与轻量化兼得"是 MIMO-WM 的核心价值主张。

### 三维权衡对比

| 维度 | MIMO-WM | Mamba | Transformer | LSTM |
|------|---------|-------|-------------|------|
| 精度（Humanoid MSE） | **19.87** ✓ | 20.18 | 28.11 | 39.93 |
| 参数量 (M) | **0.138** ✓ | 0.224 | 0.302 | 0.227 |
| 推理时间 (ms) | 2.02 | 1.66 | 10.73 | 1.12 |
| 实现复杂度 | 标准 PyTorch ✓ | 自定义 CUDA | 标准 PyTorch | 标准 PyTorch |
| 长序列扩展性 | $O(T\log T)$ ✓ | $O(T)$ | $O(T^2)$ | $O(T)$ 串行 |

## 与 Mamba 的对比：1.5% 的精度差距值不值？

MIMO-WM 与 Mamba-WM 在 Humanoid 上的精度差距仅 1.5%（19.87 vs 20.18），但综合代价差异显著：

| 维度 | MIMO-WM | Mamba-WM | 差距 |
|------|---------|----------|------|
| Humanoid MSE ($\times 10^{-2}$) | 19.87 | 20.18 | MIMO-WM 优 1.5% |
| 参数量 (M) | 0.138 | 0.224 | MIMO-WM 少 38.4% |
| 实现依赖 | 标准 PyTorch | 自定义 CUDA（`mamba-ssm`） | MIMO-WM 部署门槛低 |
| 嵌入式移植 | 容易 | 困难（需编译 CUDA 算子） | MIMO-WM 适配性强 |

!!! question "工程视角"
    为了用 Mamba 追平这 1.5% 的精度差距（且统计上 MIMO-WM 标准差为 0.23，差距在波动范围内），值得引入自定义 CUDA 算子、增加 62% 的参数量，并承担嵌入式部署的额外工程成本吗？

    在实际部署场景下，答案通常是 **不值得**。MIMO-WM 以标准 PyTorch 实现即可达到接近 Mamba 的精度，更适合资源受限的机器人平台。

## 跨数据集一致性

MIMO-WM 在 Humanoid 和 HumanoidStandup 两个数据集上 **均取得最优精度**，且参数量始终最少：

| 数据集 | MIMO-WM MSE | 次优方法 | 参数量 |
|--------|------------|---------|--------|
| Humanoid | **19.87** | Mamba 20.18 | **0.138 M**（最少） |
| HumanoidStandup | **53.10** | Transformer 53.18 | **0.138 M**（最少） |

这种跨任务一致性说明：

1. **门控 + 对角 SSM 的组合** 在不同动力学复杂度下均稳健；
2. **轻量化不牺牲精度**——MIMO-WM 用最少的参数达到了最优的预测。

## 消融实验的启示

[消融实验](../experiments/ablation.md)揭示了各组件的贡献排序：

```
SSM 骨干（+103.9%） > 残差连接（+39.8%） > 层归一化（+13.7%） > 门控（+8.9%）
```

!!! insight "门控的"四两拨千斤""
    单看绝对幅度，门控（+8.9%）似乎贡献最小。但考虑到：

    - 门控仅增加 $O(D^2)$ 参数（约占总参数 6%）；
    - 在接触动力学场景下贡献尤为显著；
    - 它赋予了对角 SSM（本身是线性、固定的）**输入自适应能力**，弥补了与 Mamba 选择性扫描的能力差距。

    因此门控是 MIMO-WM 设计中 **性价比最高** 的组件——以极小的参数代价换来了与更复杂的 Mamba 接近的精度。

## 序列长度的反直觉发现

[序列长度分析](../experiments/seqlen.md)表明，对高维人形机器人动力学，**短序列（$T=8$）反而最优**，且精度随 $T$ 增大单调下降。这与 NLP/CV 中"长上下文更好"的直觉相反，原因在于：

- 机器人状态已近似满足马尔可夫性，短历史即可；
- 长序列引入噪声步，稀释信号；
- 接触动力学具有局部性。

这一发现提示：在机器人世界模型中，**应将序列长度 $T$ 作为关键超参数仔细调优**，而非默认沿用 NLP 的长序列设置。

## 世界模型定位

MIMO-WM 被定位为一种 **轻量级世界模型**，其核心功能是 **状态转移预测**。

| 世界模型谱系 | 代表方法 | 输入 | 功能范围 | 计算开销 |
|-------------|---------|------|---------|---------|
| 完整世界模型框架 | Dreamer V3 | 视觉 + 动作 | 表征 + 动力学 + 策略 | 大 |
| 视觉-语言-动作大模型 | RT-2 | 视觉 + 语言 + 动作 | 多模态感知 + 决策 | 极大 |
| 状态动力学模型 | TD-MPC2 | 状态 + 动作 | 动力学 + 规划 | 中 |
| **轻量级状态预测** | **MIMO-WM** | **状态 + 动作** | **状态转移预测** | **极小（0.138 M）** |

!!! abstract "定位声明"
    与 Dreamer 系列等完整世界模型框架相比，MIMO-WM **不涉及** 潜在空间建模、奖励预测与策略学习，而是 **专注于状态-动作序列的高效预测**，以极低的参数开销实现高质量预测。这使得它能作为即插即用的动力学模块，嵌入 MPC 或其他规划框架。

    这种"少即是多"的设计哲学，使其特别适合资源受限的机器人部署场景。
