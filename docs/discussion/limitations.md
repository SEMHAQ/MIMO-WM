# 局限性与未来工作

本节坦诚讨论 MIMO-WM 当前的局限、已知失败场景，并展望六个未来研究方向。

## 当前局限

### 1. 仅在仿真环境验证

MIMO-WM 仅在 MuJoCo 物理仿真器的 Humanoid 和 HumanoidStandup 数据集上验证，与真机部署存在 **仿真到现实（sim-to-real）的差距**。MuJoCo 虽模拟了接触、摩擦与碰撞，但仍无法完全捕捉真实硬件的电机响应、传感器噪声、机械变形等因素。

### 2. 未涉及视觉输入

当前模型仅处理 **状态-动作向量序列**，不是端到端的视觉世界模型。机器人实际部署中，原始传感器观测（如摄像头图像）需要先经过编码才能输入 MIMO-WM，未涉及从像素到状态的端到端学习。

### 3. 推理时间未在嵌入式硬件验证

推理时间（2.02 ms）在 NVIDIA RTX 3090 桌面 GPU 上测量，**未在嵌入式硬件**（如 NVIDIA Jetson 系列、微控制器）上验证。嵌入式平台的算力、内存带宽与功耗限制可能显著改变实际推理性能。

### 4. 强凸性假设的严格性

CEM-MPC 收敛性定理（[定理 3](../method/theory.md#定理三cem-mpc-收敛性)）依赖代价函数在最优解附近满足 $\mu$-强凸性假设。在高度非凸的真实控制场景中，该假设可能不完全成立，收敛保证为局部性结论。

## 失败场景

!!! warning "已知退化场景"
    - **极长序列（$T \geq 128$）**：精度严重退化（Humanoid $R^2$ 从 0.765 降至 0.448）。长序列引入大量噪声步，稀释了预测信号（见[序列长度分析](../experiments/seqlen.md)）。
    - **剧烈碰撞/不连续动力学**：SSM 的线性递推假设在强不连续场景下可能失效，门控虽能部分缓解，但无法完全消除。
    - **分布外（OOD）数据**：训练与测试分布差异较大时，精度会显著下降。世界模型仅能可靠预测训练分布覆盖的状态-动作区域。

## 未来工作

未来工作将聚焦以下六个方向：

### 1. 优化推理速度，探索递推模式部署

训练时使用 FFT 卷积模式（吞吐高），部署时切换为 **递推模式**（单步 $O(1)$ 延迟）。未来将探索递推模式在边缘设备上的低延迟部署，结合硬件感知的算子优化。

### 2. 嵌入式硬件验证

在 **NVIDIA Jetson** 等嵌入式平台上实测推理性能，评估功耗、延迟与吞吐，验证 MIMO-WM 在资源受限场景下的可行性，并探索量化、剪枝等模型压缩技术。

### 3. 扩展到视觉输入，构建多模态世界模型

结合 CNN/ViT 视觉编码器，从图像直接预测状态，构建 **视觉-状态多模态世界模型**。这将打通从原始像素到状态预测的端到端流程，扩展 MIMO-WM 的适用范围。

### 4. 真实人形机器人验证

在真实人形机器人平台上验证状态预测与控制性能，缩小仿真到现实的差距。可能结合域随机化、快速电机适应（RMA）等迁移技术。

### 5. 结构化参数化，利用关节耦合拓扑

利用人形机器人的 **关节耦合拓扑**（如左右腿对称性、关节运动链）设计 SSM 矩阵的结构，在保持对角计算效率的同时编码物理先验，进一步提升参数效率与泛化能力。

### 6. 与强化学习结合，端到端感知-决策-控制

将 MIMO-WM 嵌入完整的 **感知-决策-控制** 闭环：以世界模型支持策略学习（如 Dreamer 式的想象训练），或与模型预测控制深度耦合，实现端到端的机器人学习。

## 总结

MIMO-WM 通过对角 SSM 与 sigmoid 门控的结合，在保持线性计算复杂度的同时实现了更强的表达能力，在人形机器人状态预测任务上取得了 **最优精度 + 最少参数** 的帕累托最优。理论分析保证了递推/卷积双模式等价性、计算复杂度优势与 CEM-MPC 收敛性。

当前局限主要在仿真到现实的迁移、视觉输入缺失与嵌入式验证三个方面，这也构成了未来工作的清晰路线图。MIMO-WM 作为轻量级状态预测世界模型，为资源受限的机器人实时控制提供了一种 **精度与效率兼得** 的可行方案。
