# 实验设置

本节描述 MIMO-WM 的实验配置，包括数据集、对比方法、统一超参数、评价指标与可复现性细节。所有实验配置遵循"统一隐空间维度与层数"的公平比较原则。

## 数据集

实验采用 MuJoCo 物理仿真器生成的 **medium** 数据集，通过 Gymnasium 环境接口采集，包含两个人形机器人数据集：

| 数据集 | 状态维度 $d_s$ | 动作维度 $d_a$ | 任务描述 |
|--------|---------------|---------------|---------|
| **Humanoid** | 348 | 17 | 平地行走，含真实接触动力学 |
| **HumanoidStandup** | 376 | 17 | 从地面起身，姿态变化大、非线性强 |

!!! note "为什么选这两个数据集？"
    - **Humanoid**：标准人形机器人行走基准，用于验证预测精度；
    - **HumanoidStandup**：起身任务涉及更大幅度的姿态变化与更强的接触非线性，用于验证泛化能力。

    两者互补，能全面考察世界模型在不同动力学复杂度下的表现。

### 数据划分与预处理

- **划分**：按 8:2 划分训练集与验证集；
- **归一化**：输入数据经 z-score 归一化（按训练集统计量计算均值与方差）；
- **采样**：训练时从训练集随机采样长度为 $T=32$ 的子序列。

## 对比方法

为公平比较，所有六个序列模型统一采用隐空间维度 $D=96$、层数 $L=2$：

| 方法 | 类型 | 隐空间/层数 | 说明 |
|------|------|------------|------|
| LSTM-WM | RNN | $D=96$, $L=2$ | 经典循环网络基线 |
| GRU-WM | RNN | $D=96$, $L=2$ | 简化门控的 RNN |
| Transformer-WM | 注意力 | $D=96$, $L=2$ | 自注意力机制，$O(T^2)$ |
| Mamba-WM | SSM（选择性） | $D=96$, $L=2$ | 需自定义 CUDA 算子 |
| TCN-WM | 卷积 | $D=96$, $L=2$ | 因果/膨胀时间卷积 |
| **MIMO-WM** | SSM（对角+门控） | $D=96$, $N=16$, $L=2$ | 本文方法 |

!!! abstract "公平比较原则"
    所有模型使用 **相同的隐空间维度 $D=96$ 与层数 $L=2$**、相同的优化器、学习率调度、序列长度、批大小与训练轮数，仅在各自特有的超参数上使用其推荐配置，确保性能差异源于模型架构本身而非调参力度。

## 统一训练配置

| 参数 | 值 |
|------|-----|
| 序列长度 | $T = 32$ |
| 批大小 | 1024 |
| 训练轮数 | 100 epoch |
| 优化器 | AdamW |
| 学习率 | $5 \times 10^{-4}$ |
| 权重衰减 | $1 \times 10^{-4}$ |
| 学习率调度 | 余弦退火（Cosine Annealing） |
| 梯度裁剪阈值 | 1.0 |
| 隐空间维度 | $D = 96$（所有模型统一） |
| 层数 | $L = 2$（所有模型统一） |
| MIMO-WM 状态维度 | $N = 16$（`d_state`） |
| 随机种子 | 42, 123, 456, 789, 1024（5 个） |

## 评价指标

| 指标 | 定义 | 方向 |
|------|------|------|
| **MSE**（均方误差） | $\mathrm{MSE} = \frac{1}{n}\sum_i \|\mathbf{s}_i - \hat{\mathbf{s}}_i\|^2$ | 越小越好（单位 $\times 10^{-2}$） |
| **$R^2$**（决定系数） | $R^2 = 1 - \dfrac{\sum_i \|\mathbf{s}_i - \hat{\mathbf{s}}_i\|^2}{\sum_i \|\mathbf{s}_i - \bar{\mathbf{s}}\|^2}$ | 越接近 1 越好 |
| **推理时间** | 单样本 $B=1$、$T=32$ 的前向时间 | 越快越好（ms） |
| **参数量** | 模型可学习参数总数 | 越少越好（M = 百万） |

## 可复现性

!!! summary "复现要点"
    - **硬件**：NVIDIA RTX 3090 GPU
    - **种子**：每组实验使用 5 个随机种子，报告 **均值 ± 标准差**
    - **模型选择**：以验证集 MSE 最优 epoch 的模型作为最终结果
    - **代码**：开源在 [SEMHAQ/MIMO-WM](https://github.com/SEMHAQ/MIMO-WM)

### 运行实验

```bash
# 安装依赖
pip install -r requirements.txt

# 运行所有实验（6 模型 × 2 数据集 × 5 种子）
python scripts/run_all_experiments.py

# 仅运行主实验
python scripts/run_all_experiments.py --experiment main

# 快速测试（单种子）
python scripts/run_all_experiments.py --quick
```

结果保存在 `experiments/` 目录：

```
experiments/
├── ablation_mimo.json      # 消融实验
├── exp4_mpc.json           # MPC 实验
├── seqlen_standup.json     # 序列长度分析
└── exp3_uncertainty.json   # 不确定性分析
```
