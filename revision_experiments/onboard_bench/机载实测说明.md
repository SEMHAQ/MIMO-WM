## 1. 文件结构（整体解压后保持目录不变）

```
deploy_bench/
├── bench_sbc.py            # 测速脚本
├── reference_io.npz        # 参考输入/输出（用于核对数值正确性）
├── models/                 # 待测 ONNX 模型（8 个）
│   ├── MIMO-WM_T8.onnx / _T16 / _T32 / _T64   ← 主模型（本次重点）
│   ├── Transformer-WM_T8.onnx / _T32           ← 对照（可选）
│   └── LSTM-WM_T8.onnx / _T32                  ← 对照（可选）
└── 发给协助者的操作说明.md
```

## 2. 环境（仅首次）

要求 **64 位系统**（`uname -m` 显示 `aarch64`），已装 Python 3。

```bash
pip3 install onnxruntime numpy
# 慢的话：
pip3 install onnxruntime numpy -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 3. 运行（建议先只跑主模型）

```bash
cd deploy_bench

# 建议：锁性能模式并把 4 线程测试绑到大核
sudo sh -c 'for p in /sys/devices/system/cpu/cpufreq/policy*; do echo performance > $p/scaling_governor; done'

python3 bench_sbc.py MIMO-WM          # 模型推理测速，约 1–2 分钟
python3 bench_mpc_sbc.py              # CEM-MPC 规划耗时，约 1 分钟
# 想更全可跑：python3 bench_sbc.py    # 8 个模型全测
```

> 两个脚本都会各自输出一份 JSON：`bench_result.json`（模型推理）与 `bench_result_mpc.json`（MPC 规划）。

## 4. 需要发回的内容

1. **终端输出全文**；
2. 同目录生成的 **`bench_result.json`** 与 **`bench_result_mpc.json`**；
3. 建议附上：`uname -a`、`cat /proc/cpuinfo | grep -m1 -E "model name|Hardware|model"`。

## 5. 脚本会测什么

- **正确性**：与参考输出逐元素比对（`diff` 应为 0，证明板上结果与训练模型一致）；
- **延迟**：每个模型 × 序列长度 × 1/4 线程，报告 mean / median / p95，并折算单步延迟；
- **内存**：模型权重体积 + 进程峰值常驻内存（VmHWM）；
- **温度**：运行前后 CPU 温度（若有传感器），用于排除降频影响；
- **环境**：平台、CPU 型号/架构/核数、Python 与 onnxruntime 版本。

## 6. x86 参考基线（仅供对照）

| 模型 | T=8 | T=16 | T=32 | T=64 |
|---|---|---|---|---|
| MIMO-WM（中位, ms） | 0.32 | 0.64 | 1.30 | 2.64 |
| 单步（ms） | 0.040 | 0.040 | 0.041 | 0.041 |

> ARM 板比 x86 慢若干倍属正常；单步延迟应基本恒定。
